# mcpcardano docs

For an AI agent working with this repository or with a running server. Read only what the task needs.

| Task | Read |
| --- | --- |
| Pay, consolidate, follow a transaction, or read a wallet through the MCP tools | [agent-guide.md](agent-guide.md) |
| Understand a wallet's UTxOs, or why a draft failed for lack of them | [utxo.md](utxo.md) |
| Install or operate it | [../deploy/README.md](../deploy/README.md) |
| Change the code | [../README.md](../README.md), then the package you touch |

The MCP tools describe themselves: their schemas are the reference for arguments and answers. These docs hold what the schemas do not say.
